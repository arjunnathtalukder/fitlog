# FitLog — Workout Library

A responsive dark-themed workout library and daily training log built for the Programming Hero FitLog assignment.

## Technologies
- Next.js 14 App Router
- React 18
- Tailwind CSS
- Lucide React icons
- React Hot Toast
- FitLog REST API
- localStorage

## Features
1. Responsive workout library with API data.
2. Dynamic workout details pages.
3. Add up to five lifts to Today’s Plan.
4. Save workouts for later.
5. Live Plan/Saved navbar counters.
6. My Plan metrics for exercises, minutes, and calories.
7. Mark workouts as Done and remove entries.
8. Sort workouts by duration, calories, or rating.
9. localStorage persistence across reloads.
10. Custom 404 page and loading states.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

The app can be deployed to Vercel, Netlify, or another Next.js-compatible host.
